# Changelog

## 0.2.0

- Light checks for common mistakes, shown as squiggles and in the Problems panel: missing required columns or values, unknown codes, badly formatted values and rows with the wrong number of cells
- New setting `gtfs.validation.enabled` (on by default)

## 0.1.0

- Hover a cell to see its column's type, whether it's required, and the label for coded values (e.g. `route_type` `3` → Bus), from a bundled copy of MobilityData's GTFS schema
- Hover a header to list all codes for that column

## 0.0.1

- Rainbow column highlighting for standard GTFS file names
